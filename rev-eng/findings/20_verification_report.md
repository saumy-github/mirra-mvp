## Corrections other agents need

Only 196-205 are grading; 206-220 are button/hole, cut/merge, outline/baseline/internal-shape point, ActivateAllPatterns and per-point grading offset APIs. Also, slot 196 is `SetGradingPairedAvatar` (not mentioned). The plugin only uses AddGradingSizeGroup, SetGradingPairedAvatarSizing and SetGradingPairedAvatarFromFile (RestPlugin_windows.cpp lines 1253, 1956-1965), so the conclusion for the plugin stands.
2. **Lane E / lane G (scope of unimplemented APIs):** Utility also has 5 thunk slots (388 RemoveGraphicStyle, 397-400 Set/GetAssetShareRoot, Set/GetBasePath). `findings/09` and any "unused useful APIs" list should not recommend these. The Rest class thunks (slots 4-10) are Qt6Core virtuals, not unimplemented APIs. The "unimplemented in 336" set is therefore 30 APIs in total (25 Pattern + 5 Utility). All other 5 classes have zero.
3. **Lane G note:** `findings/14` says Pattern has "233+1" slots; confirmed (234 incl. dtor). Utility confirmed at 409 (408+1).
4. **Lane F (position independence):** correct as stated for positions. But the avt_patch re-saved pair also differs in 94 `m4LtoW` leaves (3,906 B) and `fBaseFeatureBustCircum` (3 B, delta 0.41); the claim "only listFeatureValues differ" in the un-imported patched file holds, but after the CLO re-save other derived/joint-matrix bytes change. 5. **Lane H:** all CSV claims check out. Two refinements: (a) a non-numeric or out-of-range field-3 throws (strtod end==start or ERANGE) with no handler in 0x50e4d80, rather than being "skipped"; (b) only *unknown keys* are skipped, and the store guard is `index < 67` (signed `jge` skip), so a lookup that returns a negative value for an unknown key would index before the array. Lane H states unknown keys are "silently skipped", which implies the lookup returns >=67 or the map insert path differs; I did not decode 0x50d9250's miss path (it appears to return a large sentinel), so mark that UNVERIFIED rather than assuming.
6. **Lane E units:** keep area unit as "inferred mm^2"; constants (1e-6, 1e-5, 100, 360, -180) are all independently confirmed.
